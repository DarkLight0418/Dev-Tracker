[내가 생각하는 Dev Tracker의 문제 정의 초안]

1. 어떤 사람이:
   → 기획 단계 다음 절차를 밟으며 개발 및 단위 테스트 중인 개발자

2. 어떤 상황에서:
   → 개발 중 버그 및 문제가 발견되었고 해결한 상황

3. 어떤 문제를 겪고 있고:
   → 그 로그를 자동으로 남기기 어렵다는 문제

4. 현재는 어떻게 해결하고 있는데:
   → 깃허브에 이슈 로그를 MD 파일 등으로 커밋 중

5. Dev Tracker가 무엇을 개선해줬으면 하는가:
   → 이슈 로그를 자동으로 생성해서 정리 커밋 반영해주면 좋겠다.

6. 이 프로젝트를 처음 만들려고 했던 개인적인 이유:
   → Spring Boot 등 부트캠프에서 배웠던 기술 복습 및 연마
